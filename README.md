🌄 LifeOS

LifeOS is a personal life management system designed to improve discipline, consistency, financial growth, fitness, and long-term goals.

Features

- 🔐 Secure Passcode Login
- 🏠 Dashboard
- 🌱 Daily Standards
- 💰 Finance Tracker
- 💪 Fitness Tracker
- 🌟 Private Vision Board
- ⚙️ Settings

Tech Stack

Frontend

- HTML5
- CSS3
- JavaScript

Backend

- Node.js
- Express.js

Database

- PostgreSQL

Hosting

- GitHub
- Render

Version: 1.0
